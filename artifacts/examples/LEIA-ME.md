# Exemplos sintéticos

- `draft.md` / `draft.json`: saída do `npm run generate` sobre `fixtures/`.
- `CASE.md`: cópia do case técnico.
- Entrada: pasta `/fixtures` na raiz do source (PRs, commits, tarefas, anotações, associações). Tudo rotulado `synthetic-fixture`.

Não são realizações de Helison Dias.
